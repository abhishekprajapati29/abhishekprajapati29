## Selected work

### [Assign Project](https://github.com/abhishekprajapati29/assign-project)

A full-stack project-management application designed to centralize task tracking, bug reporting, file sharing, and team activity.

- **Problem:** Project information becomes fragmented across task lists, conversations, files, and bug reports.
- **Approach:** Combined those workflows in one MERN application with authentication, project dashboards, collaboration features, and activity tracking.
- **Explore:** [Source code](https://github.com/abhishekprajapati29/assign-project) · [Live application](https://assign-project.onrender.com/)

### [Hierarchical Table](https://github.com/abhishekprajapati29/hierarchical-table)

An interactive allocation table for working with parent-child financial or planning data.

- **Problem:** Updating values in a hierarchy requires consistent propagation between leaf rows, parent totals, and calculated variance.
- **Approach:** Implemented percentage and direct-value allocation with automatic parent/child recalculation in React.
- **Explore:** [Source code](https://github.com/abhishekprajapati29/hierarchical-table) · [Live demo](https://abhishekprajapati29.github.io/hierarchical-table/)

### [Image Text Extraction](https://github.com/abhishekprajapati29/Image-text-extraction-project)

A document-processing application that extracts searchable text from uploaded images.

- **Problem:** Manually transcribing text from receipts, scans, and screenshots is slow and error-prone.
- **Approach:** Integrated OCR with an authenticated application for upload, extraction, history, and usage visibility.
- **Explore:** [Source code](https://github.com/abhishekprajapati29/Image-text-extraction-project)

## Currently engineering

### DataForge Enterprise

A privacy-aware large-file processing platform using React, Rust/WebAssembly, Java, Spring Boot, Spring Batch, PostgreSQL, messaging, and AWS.

The project focuses on local file validation, direct cloud uploads, asynchronous processing, idempotent jobs, real-time progress, tenant isolation, and reproducible performance benchmarks.

### SeatGuard

A distributed reservation system built to demonstrate and prevent double booking under concurrent traffic.

The project will include an interactive concurrency lab comparing an unsafe implementation with a protected Spring Boot, PostgreSQL, and Redis workflow using transactions, locks, and idempotency keys.
